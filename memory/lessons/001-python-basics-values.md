Python works with values. 3 is an integer, 2.5 is a floating-point number, and "hello" is text (a string). An assignment gives a name to a value:

```python
price = 12
quantity = 3
total = price * quantity
print(total)
```

Here, * multiplies two numbers, so print(total) displays 36. The = sign assigns a value; it does not ask whether two things are equal. Code runs from top to bottom.
